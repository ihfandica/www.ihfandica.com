Sistem Pengocok Arisan Digital

Unggah file arisan Anda, kelola riwayat secara otomatis, dan unduh data pencadangan dalam satu file tunggal. Jika tidak punya data (.txt) silakan ketik manual di kotak yang tersedia. Semua proses dilakukan di lokal, tidak ada data yang di unggah. :-)

Sebelum keluar, unduh data terlebih dahulu agar dapat digunakan kembali di masa mendatang tanpa memasukan data ulang.
Lihat langkahnya
  • Pilih file arisan .txt jika sudah punya. Apabila belum, masukkan manual dalam kotak "Pratinjau File / Edit Manual:".
  • Setelah data dipilih, kotak akan terisi otomatis. Batas "== SUDAH KELUAR ==" memisahkan peserta aktif (atas) dan riwayat yang sudah keluar (bawah).
  • Sistem secara otomatis mengelola nomor putaran (misal: Ihfandi = 1). Pemenang dari putaran sebelumnya otomatis dikecualikan sepanjang putaran berlangsung.
  • Ketika masuk ke dua putaran berikutnya (misal: Putaran 3), variasi peserta dari Putaran 1 otomatis dikembalikan ke dalam roda.
  • Tekan tombol "Putar Rodanya" atau tombol PUTAR di tengah roda.
Reset: Mengembalikan data yang telah terkocok menjadi tidak terkocok semua.
Clear: Menghapus semua data, termasuk yang telah dipilih melalui menu Pilih File Arisan .txt.
